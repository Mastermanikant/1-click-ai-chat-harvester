# GRPO (Group Relative Policy Optimization) Breakdown

> Harvested via 1-Click AI Chat Harvester (0KB Idle RAM)

### Mathematical Formulation

$$
\mathcal{J}_{GRPO}(\theta) = \mathbb{E} \left[ \frac{1}{G}\sum_{i=1}^{G} \min\left(r_i A_i, \text{clip}(r_i, 1-\epsilon, 1+\epsilon) A_i \right) \right]
$$

### PyTorch Implementation

```python
import torch

def compute_group_advantages(rewards: torch.Tensor, eps: float = 1e-8) -> torch.Tensor:
    """Computes relative advantages normalized across group samples G."""
    mean = rewards.mean(dim=-1, keepdim=True)
    std = rewards.std(dim=-1, keepdim=True)
    return (rewards - mean) / (std + eps)
```

| Parameter | Type | Role |
| :--- | :--- | :--- |
| `rewards` | Tensor | Sample outputs scored by rule-based verifier |
| `eps` | float | Numerical stability epsilon ($10^{-8}$) |
